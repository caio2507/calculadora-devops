🚀 Calculadora DevOps & CI/CD Simulator
Projeto prático desenvolvido para a disciplina de Cultura e Prática DevOps (UNIPÊ).

📌 Tecnologias e Práticas:
- Linguagem e Build: Java 21 + Apache Maven
- Testes Unitários: JUnit 5 (com cobertura de exceções)
- Fluxo de Git: Gitflow (main, develop, feature/*)
- CI/CD: GitHub Actions (pipeline automatizada de build e testes)
- Interface: HTML5, Tailwind CSS e Simulador Interativo de Pipeline
