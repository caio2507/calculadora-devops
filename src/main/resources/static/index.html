Estrutura de Testes Unitários (JUnit 5)

CalculadoraTest.java

@Test
public void testDividirPorZeroExcecao() {
    Calculadora calc = new Calculadora();
    assertThrows(IllegalArgumentException.class, () -> {
        calc.dividir(10.0, 0.0);
    });
}

Garantia da Esteira CI

Se qualquer asserção falhar, o comando mvn test retorna código de erro e bloqueia o Pull Request no GitHub.

Gitflow Integration

Cada branch de feature/* executa os testes antes de realizar o merge com a develop ou main.
